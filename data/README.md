# Dataset — SDALLE

## Overview

This project uses the **SDALLE** (Surface-electrode Dataset for Activity recognition of the Lower Limb Extremities) dataset.

## Official Source

- **Zenodo Record:** [https://zenodo.org/records/14841611](https://zenodo.org/records/14841611)
- **DOI:** 10.5281/zenodo.14841611

## Important Notice

**The raw SDALLE dataset is not redistributed by this repository.** Researchers must obtain it directly from the official Zenodo source linked above.

## Dataset Description

- **Subjects:** 9
- **Activities:** 4 (jogging, stairs down, stairs up, walking)
- **Sensors:** 8 surface sensors per subject
- **Channels per sensor:** 7 (1 EMG + 3 accelerometer + 3 gyroscope)
- **Total channels:** 56
- **EMG sampling rate:** ~1259.2593 Hz
- **IMU sampling rate:** ~148.1481 Hz

## Expected Local Directory Structure

After downloading and extracting the dataset, place it as follows:

```
data/
├── raw/
│   └── SDALLE/
│       ├── Subject_1/
│       │   ├── jogging_1.csv
│       │   ├── jogging_2.csv
│       │   ├── stairs_down_1.csv
│       │   ├── stairs_down_2.csv
│       │   ├── stairs_up_1.csv
│       │   ├── stairs_up_2.csv
│       │   ├── walking_1.csv
│       │   └── walking_2.csv
│       ├── Subject_2/
│       │   └── ...
│       └── Subject_9/
│           └── ...
└── processed/           (generated by build_datasets.py)
    ├── E1_emg_only/
    ├── E2_imu_only/
    ├── E3_rate_matched/
    └── E4_multirate/
```

Each subject directory contains CSV files for each activity trial. Each CSV file contains time-synchronised multichannel sensor data with 56 columns (8 sensors × 7 channels).

## Processed Data

The `data/processed/` directory is generated by running `python3 src/build_datasets.py` and contains windowed, normalised NumPy arrays (`.npz`) for each experiment and LOSO fold. These derived files are not included in the repository due to their size (~3.6 GB total) and because they can be regenerated from the raw data.
