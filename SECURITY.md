# Security Policy

## Supported Versions

This repository contains research software and static benchmark artifacts. Security updates are applied to active branches:

| Version | Supported |
|---|---|
| 2.0.x | :white_check_mark: Supported |
| 1.0.x | :x: Frozen historical release (maintenance only) |

## Reporting a Vulnerability

If you discover a security vulnerability or potential privacy leak (e.g., accidental exposure of personal data or credentials) within this repository:

1. Please do **NOT** open a public issue.
2. Email the corresponding author directly:
   - **Dr. Sona G:** `sona@gcetly.ac.in`
3. Include a description of the vulnerability, affected files, and proof-of-concept steps.
4. The research team will respond within 48 hours and coordinate remediation.
